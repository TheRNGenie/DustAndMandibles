# Dust & Mandibles

Two homesteaders hold facing cliff-top outposts across a dusty canyon. Giant bugs climb
both cliffs in waves, and **your turrets can only defend your partner's cliff**, never your own.

Built with Godot 4 and GDScript. Every mesh, texture, shader and sound is generated by code.

**Status:** M0-M4 built (10 waves, full roster, boss) and tested by automated runs; needs a two-person playtest and export templates for a shareable build. See [PLAN.md](PLAN.md) and [DECISIONS.md](DECISIONS.md).

## Requirements
- Godot 4.5 or newer (standard build, not .NET): `winget install GodotEngine.GodotEngine`
- Later, for generating audio: Python 3 with `pip install numpy scipy`

## Shareable build
```
godot --headless --path D:\DustAndMandibles --export-release "Windows Desktop" builds/windows/DustAndMandibles.exe
```
The .exe is self-contained: send it to a friend, one of you hosts, the other joins by IP (or pastes the invite from the pause menu's Social tab). Allow it through Windows Firewall when asked.

## Run
Open the folder in Godot (Import > select `project.godot`) and press F5, or from a terminal:

```
godot --path D:\DustAndMandibles
```

The main menu offers **Host** (you get the west cliff) and **Join** (IP, default 127.0.0.1, port 24565; you get the east cliff). Tick **Ready** on both; the game starts when both players are ready. The host can also **Start alone** for testing.

Two local windows that connect automatically: `powershell -ExecutionPolicy Bypass -File tools\run_two_local.ps1`

Command-line flags (after `--`): `--host`, `--join[=ip]`, `--name=X`, `--solo`, `--fast` (short phases), `--debug` (F6 skips a phase), `--east` (when running `scenes/world.tscn` directly, offline).

Headless smoke test: `godot --headless --path D:\DustAndMandibles --quit-after 300`

Unit tests: `godot --headless --path D:\DustAndMandibles -s res://tests/run_tests.gd`

Automated wave test (no window): `godot --headless --path . res://scenes/world.tscn -- --debug --fast --autobuild --light --autokill --soak=900` (add `--god` to make Homesteads invulnerable)

Regenerate sounds and music: `python tools/audio/make_sfx.py` and `python tools/audio/make_music.py`

## Controls
| Action | Key |
|---|---|
| Move | WASD / arrow keys |
| Look | Mouse |
| Sprint | Shift (forward) |
| Jump / mantle | Space (hold near a ledge to climb onto it) |
| Slide | Ctrl or C while running |
| Fire | Left mouse |
| Aim / zoom | Hold right mouse |
| Reload | R |
| Interact / hold to repair | E |
| Build menu | B: pick a category (Farming, Cliff Turrets, Tactical, Last Resorts) and an item, click to place. B reopens the menu, wheel cycles, X demolishes, right click leaves |
| Upgrade the turret you look at | U (chitin) |
| Hotbar | 1-3 any weapons, 4-6 carried harvest, 7 medicine (herbs, heal), 8 water bucket |
| Q | Drop the weapon in your hand (E picks a dropped weapon up) |
| Pick seed / shop item / vegetable to sell / house upgrade | F |
| Ready / skip build phase | G |
| Skip phase (with --debug) | F6 |
| Pause menu (settings, remapping, invite) | Esc |
| Debug cheats (with --debug) | F6 skip phase, F7 +500 scrap, F8 spawn bug, F9 god mode, F10 show lanes |
| Debug overlay | F3 |

## Layout
```
autoload/   global singletons (InputSetup, GameState; NetworkManager etc. from M1)
data/       world layout constants, later BugDef/TurretDef/CropDef resources
gen/        procedural asset builders (cliffs, buildings, props, weapons, materials)
scenes/     world, player, props, ui, vfx
shaders/    toon, outline, cliff strata, sky, vfx star
```
