# Dust & Mandibles

Two homesteaders hold facing cliff-top outposts across a dusty canyon. Giant bugs climb
both cliffs in waves, and **your turrets can only defend your partner's cliff**, never your own.

Built with Godot 4 and GDScript. Every mesh, texture, shader and sound is generated by code.

**Current milestone:** M0 (graybox and shader kit). See [PLAN.md](PLAN.md) and [DECISIONS.md](DECISIONS.md).

## Requirements
- Godot 4.5 or newer (standard build, not .NET): `winget install GodotEngine.GodotEngine`
- Later, for generating audio: Python 3 with `pip install numpy scipy`

## Run
Open the folder in Godot (Import > select `project.godot`) and press F5, or from a terminal:

```
godot --path D:\DustAndMandibles
```

Spawn on the east cliff instead: `godot --path D:\DustAndMandibles -- --east`

Headless smoke test: `godot --headless --path D:\DustAndMandibles --quit-after 300`

## Controls
| Action | Key |
|---|---|
| Move | WASD / arrow keys |
| Look | Mouse |
| Sprint | Shift (forward) |
| Jump / mantle | Space (hold near a ledge to climb onto it) |
| Slide | Ctrl or C while running |
| Fire | Left mouse |
| Reload | R |
| Interact | E (from M1) |
| Release / capture mouse | Esc / click |
| Debug overlay | F3 |

## Layout
```
autoload/   global singletons (InputSetup, GameState; NetworkManager etc. from M1)
data/       world layout constants, later BugDef/TurretDef/CropDef resources
gen/        procedural asset builders (cliffs, buildings, props, weapons, materials)
scenes/     world, player, props, ui, vfx
shaders/    toon, outline, cliff strata, sky, vfx star
```
